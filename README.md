# ⛺ 祿野營地訂位管理系統 (Lu-Ye Campsite Booking System)

一套基於 **Python** 與 **Streamlit** 打造的現代化、卡片式營地訂位與客戶管理 Web 應用程式。專為「祿野營地」客製化設計，提供即時營位監控、彈性訂單索引、操作稽核歷程，以及 Google Drive 雲端雙向備份降級機制。

---

## 🌟 核心特色與功能規格

### 1. 營地規格與費用自動核算
- **三大區域管理**：
  - **雨棚區**：共 8 帳，營位規格寬 4 米深 6 米（含 1 車），收費 **NT$ 1,200 元/帳/晚**。
  - **草地區**：共 4 帳，開闊天然草坪（含 1 車），收費 **NT$ 1,200 元/帳/晚**。
  - **通舖房間**：共 2 間（每間容納 4 人，含客廳與廁所，無衛浴，含戶外雨棚區與 1 車），收費 **NT$ 2,000 元/間/晚**。
- **夜衝服務 (Night Rush)**：
  - 前晚 18:00–23:00 入場，費用為原價之 **50%**（雨棚/草地: NT$ 600，通舖房間: NT$ 1,000）。
- **即時費用試算**：輸入入住/退房日期、帳數、勾選是否夜衝，系統自動計算總額。

### 2. 安全登入與管理人權限 (PIN 碼機制)
- 進入系統時強制要求輸入 **4 位數 PIN 碼**。
- **預設 PIN 碼與管理者**：
  - `0218` ➔ **KC**
  - `0311` ➔ **Aileen**
- **「管理人帳號管理」功能**：
  - 可於獨立管理頁面新增管理員與自訂 4 位數字 PIN 碼。
  - 支援刪除管理人帳號（自動寫入 `data/admins.json`）。
  - **防呆保護**：系統強制保留至少一組有效 PIN 碼，防止誤刪導致系統鎖死。

### 3. 完整露營客資料欄位與三大核心索引
- **豐富訂位欄位**：
  - 主要入住日期、退房日期
  - 露營人姓名、露營人電話
  - 預約區域（雨棚區 / 草地區 / 通舖房間）
  - 預約數量（帳數 / 間數）
  - 是否夜衝（開關勾選）
  - 來過次數（輸入電話號碼後自動分析歷史到訪頻率，並支援手動微調）
  - 客戶標籤：`好客人` (綠色徽章)、`需要注意的客人` (紅色警告)、`一般`
  - 空白文字備註（自由記錄特殊需求、同伴資訊、車牌號碼等）
  - 自動產生專屬訂單編號（如 `LY-20261001-XXXX`）
- **頂部三大核心快速搜尋索引**：
  1. **日期條件**：所有日期 / 今天 / 未來 7 天 / 自訂特定日期 / 自訂日期區間。
  2. **露營人姓名**：支援模糊關鍵字比對。
  3. **露營人電話**：支援模糊號碼比對。

### 4. Excel / CSV 一鍵匯入與匯出 (Import / Export)
- **一鍵匯出**：即時打包營地所有訂單記錄，匯出為格式工整的 `.xlsx` (Excel) 或 `.csv` 檔。
- **批次匯入**：提供標準 Excel 範本下載；管理者可直接上傳現有試算表，系統自動驗證格式、計算費用並批次新增。

### 5. 操作日誌 Note Log (Audit Log)
- 完整紀錄所有營運操作事件：
  - 新增訂單、修改訂單、刪除訂單
  - 管理人新增與移除
  - 批次匯入與雲端備份事件
- 紀錄格式包含：`時間戳記` + `操作者名字 (如 KC/Aileen)` + `操作動作` + `具體異動細節`。
- 專屬日誌分頁，提供關鍵字篩選、人員過濾與匯出 CSV 功能。

### 6. Google Drive 雲端同步 (Google Drive API) 與平滑降級機制
- **預設對接資料夾 ID**：`1JFzbSQuolGniXeAeeaX3okbUZPQ-Rzok`（資料夾名稱：**DVCG**）。
- **自動異動備份**：每當建立、修改、刪除訂單或調整管理人時，自動觸發背景打包與同步備份。
- **無縫本地平滑降級 (Graceful Fallback)**：
  - 在未設定 Google 服務帳號 (Service Account) 金鑰的情況下，系統會自動在 `data/` 本地目錄保存 SQLite 資料庫與 Excel/JSON 備份檔案，並於 UI 提示「本地儲存模式」，絕不影響系統正常操作。
  - 隨時可在介面中直接上傳 `service_account.json` 即可一鍵銜接雲端備份。

```text

    ├── admins.json         # 管理人 PIN 碼設定檔
    ├── service_account.json# (選用) Google Cloud Service Account 憑證金鑰
    └── 祿野營地資料庫完整備份_*.xlsx # 自動定時或手動備份檔案
```

## 🚀 快速開始與安裝步驟

### 步驟 1：安裝 Python 環境
建議使用 **Python 3.9 ~ 3.13** 版本。

### 步驟 2：安裝相依套件
在專案根目錄下開啟終端機（Terminal / PowerShell），執行：
```bash
pip install -r requirements.txt
```

### 步驟 3：啟動系統 Web 服務
```bash
streamlit run app.py
```
啟動後，瀏覽器將自動開啟管理系統頁面（預設為 `http://localhost:8501`）。

## ☁️ Google Drive 雲端自動同步設定指南

若欲將備份檔案自動上傳至 Google Drive 目標資料夾（`DVCG`，ID: `1JFzbSQuolGniXeAeeaX3okbUZPQ-Rzok`）：

1. 至 [Google Cloud Console](https://console.cloud.google.com/) 建立專案並啟用 **Google Drive API**。
2. 建立「**服務帳號 (Service Account)**」，並下載其 JSON 金鑰檔案。
3. 將目標雲端資料夾 `DVCG` 的**共用權限**分享給該服務帳號的電子郵件地址（例如 `xxx@project.iam.gserviceaccount.com`），並賦予「**編輯者**」權限。
4. 憑證啟用途徑（二擇一）：
   - **方式 A (介面上傳)**：登入系統後，前往「**☁️ 雲端備份與同步**」分頁，直接於頁面上傳該 JSON 金鑰檔。
   - **方式 B (檔案放置)**：將該 JSON 檔命名為 `service_account.json` 並放置於專案的 `data/` 目錄中。
5. 完成後重新連線，狀態即會切換為「🟢 已連線正常」，未來每次訂單異動均會自動將最新全量 Excel 備份推送至雲端資料夾中。

## 🛡️ 資料安全性與備份保證

1. **雙軌備份**：每次異動均同時更新本地 SQLite 資料庫，並產製獨立時間戳記的 Excel 檔案。
2. **防呆驗證**：退房日期早於入住日期檢測、手機格式檢測、容量超額提醒、管理員防呆（至少保留一組）。
3. **不可竄改日誌**：任何關鍵資料變更皆寫入操作日誌，並可隨時匯出備查。
